# 6. Git & Workflow

- **Commit Format:** Use the structured emoji format:
  - `feat`: New feature
  - `fix`: Bug fix
  - `refactor`: Internal logic changes
  - `docs`: Documentation updates
  - `chore`: Tooling/Dependency updates
  - ✅ (Task complete), 🐛 (Bug fixed), ♻️ (Refactor), 📄 (Docs), 🔧 (Config)
- **Feature Branches:** All work MUST be completed in focused feature branches (e.g., `feat/issue-number-description`) and merged via Pull Request.
- **Git Push:** NEVER use `--no-verify`.
- **Terminal:** Assume Git Bash environment. Use forward slashes for paths.
